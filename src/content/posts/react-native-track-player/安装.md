# React Native Track Player 安装指南

版本：4.1

## 一、安装

### 1.1 稳定版

#### NPM
```bash
npm install --save react-native-track-player
```

#### Yarn
```bash
yarn add react-native-track-player
```

### 1.2 开发版/尝鲜版

若你因某些原因需要使用尚未正式发布的更新版本，可安装夜间版，该版本是对`main`分支代码的自动构建版本，会每24小时发布至npm。

#### NPM
```bash
npm install --save react-native-track-player@nightly
```

#### Yarn
```bash
yarn add react-native-track-player@nightly
```

## 二、iOS 环境配置

iOS 平台需要额外执行一些 Android/网页平台无需操作的步骤。

### 2.1 启用 Swift 模块

由于iOS端模块基于Swift开发，若你使用的是标准React Native项目，则需要为项目添加Swift支持。你可以通过在Xcode项目中添加一个Swift文件（可命名为`dummy.swift`）来快速实现，当Xcode提示是否生成桥接头文件时，选择“是”即可。

### 2.3 执行Pod安装

你需要运行`pod install`命令来安装iOS原生依赖：

```bash
cd ios && pod install
```

## 三、网页端环境配置

RNTP支持网页平台。其网页端实现基于shaka-player，而shaka-player是RNTP的可选对等依赖。若你要部署网页端应用，需在项目中直接安装`shaka-player`：

#### NPM
```bash
npm install --save shaka-player
```

#### Yarn
```bash
yarn add shaka-player
```

若你使用的HLS流包含MPEG2-TS格式内容，可能需要启用转封装支持，此时需安装`mux.js`：

#### NPM
```bash
npm install --save mux.js
```

#### Yarn
```bash
yarn add mux.js
```

## 四、Expo 环境适配

现在你可以在Expo项目中使用React Native Track Player了。

需要注意的是，尽管已有大量开发者成功在Expo中集成RNTP，但该项目的维护者本身并不使用Expo，因此他们针对Expo相关问题的排查能力有限。

如需开始集成，需先为你的Expo应用创建开发构建版本，再安装React Native Track Player。

以下是实现后台音频播放所需的配置：

- iOS：在app.json中开启后台音频播放权限
- Android：设置为应用关闭时停止音频播放
